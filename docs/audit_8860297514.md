# Codex Regression Audit: 8860297514

Match ran on `build=4a8bd7d`.

## What the log showed

- Telemetry saw point-blank enemies (`enemy-dist` around 64-120), but `hero-pass-*` almost never fired.
- `fwd-ahead`, `fwd-fallback`, `fwd-push`, and `fb-skip` were still very noisy, matching the visual back-and-forth movement.
- `AIB_VisualAFKStep` could strafe while an enemy hero was already attackable, which looked like dancing instead of trading.
- `creep-aggro` still used a broad 68% HP fallback in one module, making moderate creep damage too likely to override normal laning.

## Fixes

- Added `hero-contact` guard before visual-AFK and normal intent arbitration. It attacks a nearby enemy hero in range, chases a very close enemy when safe, or kites to safety at critical HP.
- Visual-AFK now yields when an enemy hero is already attackable, so it cannot replace an attack with a strafe.
- Forwardness/fallback movement is suppressed while a hero is close (`fwd-suppressed-hero`), leaving the tick to contact trade, last-hit, idle-creep attack, or global anti-idle.
- Lowered default `creep_aggro_relief_hp` from `0.68` to `0.55` in config and survival fallback.
- `match_stats.py` now counts `hero-contact-atk` and `hero-contact-chase` as hero actions for `ignored-nearby-hero` alerts.
