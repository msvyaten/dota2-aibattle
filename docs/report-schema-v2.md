> Дата: ‹дд.мм.2026›. Машина: Windows / Shadow PC. Опирается на подтверждённые Phase 1 + Phase 2.
> Плейсхолдеры помечены «‹…›» — заменить цифрами/наблюдениями из логов матчей.

## 1. Что добавляет Schema v2

Расширение управляемости агента после доказанной базовой концепции (промпт → поведение).

**Что нового по сравнению с v1 (4 булевых поля):**
- Управление стало **непрерывным (0–1)** — «диммер» вместо «выключателя»: те же поля дают
  кратно больше стилей и плавные градации.
- Набор расширен до **6 диалов** (дуэльно-наблюдаемых):
  `harass_desire`, `farm_focus`, `forwardness`, `ability_aggro`, `rune_control`, `retreat_caution`.
- Введён второй тип управления — **правила** (событие→действие), первое: `respawn_behavior`
  (поведение после смерти: телепорт к вышке / на линию / пешком).

**Цепочка без изменений:** `промпт → LLM → JSON → playstyle_*.lua → поведение бота`.

## 2. Методология

Та же, что доказала Phase 1/2: зеркальный 1v1 Sniper vs Sniper, агрессивный конфиг против
пассивного, контроль через обмен сторон. Для v2 добавлены **прицельные прогоны на один диал**:
меняем ОДНО значение между двумя матчами, остальное не трогаем, и смотрим, меняется ли
конкретная наблюдаемая метрика. Доказательство = цифра из стат-дампа или строка из
`console.<matchid>.log`, не «на глаз».

## 5. Вывод

‹Заполнить после валидации. Шаблон:›
Schema v2 расширяет управление с 4 булевых полей до 6 непрерывных диалов + правил, сохраняя
прозрачность и предсказуемость. Подтверждено ‹X из 6› диалов + ‹правило respawn›. Управление
остаётся **градуированным и читаемым** — промпт задаёт не «вкл/выкл», а степень поведения,
что усиливает продуктовую историю (богаче «личности» агентов при сохранении объяснимости).

## 6. Охват и дальнейшее (честная рамка)

- Проверено: 1 герой (Sniper), 1v1, дуэльные рычаги.
- **Отложено в v3:** командные диалы (ганки/пуш/защита/Рошан/варды — нужен 5v5),
  `execute_threshold` и адаптивные `item_rules` (сейчас на ветке, спят до своей валидации),
  плавная градация `forwardness`, генерация item-сборок из промпта в бэкенде.
- Гардрейлы: диалы клампятся 0–1, правила — по белому списку; LLM выдаёт только числа и
  enum, без кода → агенты предсказуемы и объяснимы (нужно для честной линии ставок).

## 7. Воспроизведение

- Скрипты: `...\dota 2 beta\game\dota\scripts\vscripts\bots\`
- Запуск 1v1: лобби 1v1 Solo Mid, читы ON, хост зрителем, залить Local Dev Script ботов,
  кикнуть лишних (`kick 1..4`, `kick 6..9`), `-condebug -console`.
- Генерация конфига из промпта: `python generate_playstyle.py --radiant "…" --dire "…"
  --output-dir "...\Customize"` (нужен свой `OPENAI_API_KEY`).
- Метрики — из финального стат-дампа в конце `console.<matchid>.log`.
