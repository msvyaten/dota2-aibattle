# Canonical Playstyles

Stable LLM playstyles live in:

- `canonical_pusher.lua`: map control and tower pressure.
- `canonical_ganker.lua`: hero pressure and roaming aggression.

`playstyle_radiant.lua` and `playstyle_dire.lua` are live bindings to these canonical presets. If a match needs a temporary experiment, archive the old binding first and keep the canonical presets unchanged.
